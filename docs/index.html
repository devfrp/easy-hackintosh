Le montage manuel, fait à ta place

Monter un hackintosh à la main, c'est lire un guide de cent pages, deviner quels kexts s'appliquent à ta carte, écrire un config.plist à la pince, puis fabriquer une clé USB depuis un Mac que tu n'as pas. easy-hackintosh fait les quatre : il demande la version de macOS, télécharge la recovery officielle Apple, lit ton matériel réel et écrit un EFI OpenCore qui lui correspond — validé par ocvalidate avant d'être écrit sur le support.

01

La chaîne, de la question au support bootable

Sept étapes enchaînées par un seul assistant. Tout atterrit dans build/ — efface le dossier pour repartir de zéro.

1 · versionChoix de la version de macOS, de High Sierra à Tahoe (26) — non interactif avec EH_VERSION=sequoia
↓
2 · recoveryTéléchargement de la recovery officielle depuis les serveurs Apple, via macrecovery
↓
3 · scanLecture du matériel réel : CPU, iGPU/dGPU, Ethernet, Wi-Fi, codec audio, NVMe — écrit dans build/hardware.json
↓
4 · kextsInstallation des kexts correspondants : Lilu, VirtualSMC, WhateverGreen, AppleALC, pilotes réseau…
↓
5 · configGénération du config.plist OpenCore : quirks et SMBIOS adaptés à la machine
↓
6 · ocvalidateValidation de la configuration par l'outil officiel OpenCore avant toute écriture
↓
7 · supportImage ISO hybride bootable (Linux : clé USB ou VM QEMU) ou écriture directe sur clé USB (Windows)

03

Installer

Sous Windows, ouvre PowerShell en Administrateur pour l'écriture USB. get.ps1 installe Python et Git via winget s'ils manquent ; le partitionnement passe par diskpart, fourni avec Windows.

Linux

# assistant complet
curl -fsSL https://raw.githubusercontent.com/devfrp/easy-hackintosh/main/get.sh | sh

# dépendances (Arch)
sudo pacman -S --needed python mtools gptfdisk \
  pciutils usbutils qemu-full edk2-ovmf

Windows (PowerShell)

# console Administrateur pour l'USB
irm https://raw.githubusercontent.com/devfrp/easy-hackintosh/main/get.ps1 | iex

Manuellement

git clone https://github.com/devfrp/easy-hackintosh.git
cd easy-hackintosh
python3 easy_hackintosh.py   # Windows : python

Sous-commandes

python3 easy_hackintosh.py         # tout l'assistant
python3 easy_hackintosh.py scan    # scan matériel seul
python3 easy_hackintosh.py efi     # régénère l'EFI
python3 easy_hackintosh.py image   # refabrique le support

04

À savoir avant de lancer

Aucun outil ne garantit un boot du premier coup. Voilà exactement où sont les limites.

  • EN LIGNE
    Installeur « recovery » · macOS est téléchargé pendant l'installation — connexion requise. Un installeur complet hors-ligne exige createinstallmedia, qui n'existe que sous macOS.
  • AUTOMATISÉ
    ACPI, USB et Wi-Fi · SSDT universels boot-safe (EC, USBX, AWAC, plugin-type, PNLF), USB via SSDT-RHUB, et le kext Wi-Fi choisi selon la version — Intel AirportItlwm ou Broadcom AirportBrcmFixup.
  • POINT DE DÉPART
    L'EFI reste à affiner · mapping USB précis via USBToolBox (Windows) ; Wi-Fi Intel sous Sequoia/Tahoe sans build stable — repli sur le build Sonoma, à vérifier ; ACPI très spécifique → SSDTTime et le guide Dortania.
  • TAHOE (26)
    Dernière version macOS Intel · mais seulement 4 modèles réels acceptés (MacPro7,1, MacBookPro16,1/16,2, iMac20,1/20,2) — l'installeur refuse un SMBIOS spoofé qui n'en fait pas partie. macOS 27 sera Apple Silicon uniquement.
  • LAPTOPS
    Plus délicats · batterie, veille, Wi-Fi et USB demandent presque toujours des réglages supplémentaires.
