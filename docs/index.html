Le montage manuel, fait à ta place

Monter un hackintosh à la main, c’est

  • lire un guide de cent pages
  • deviner quels kexts s’appliquent à ta carte
  • écrire un config.plist à la pince
  • fabriquer une clé USB depuis un Mac que tu n’as pas

easy-hackintosh fait les quatre :

  • il demande la version de macOS
  • télécharge la recovery officielle Apple
  • lit ton matériel réel
  • et écrit un EFI OpenCore qui lui correspond, validé par ocvalidate avant d’être écrit sur le support

De la question au support bootable

Sept étapes enchaînées par un seul assistant. Tout atterrit dans build/ : efface le dossier pour repartir de zéro.

  1. version

    Choix de la version de macOS, de High Sierra à Tahoe (26) ; non interactif avec EH_VERSION=sequoia

  2. recovery

    Téléchargement de la recovery officielle depuis les serveurs Apple, via macrecovery

  3. scan

    Lecture du matériel réel : CPU, iGPU/dGPU, Ethernet, Wi-Fi, codec audio, NVMe, écrit dans build/hardware.json

  4. kexts

    Installation des kexts correspondants : Lilu, VirtualSMC, WhateverGreen, AppleALC, pilotes réseau…

  5. config

    Génération du config.plist OpenCore : quirks et SMBIOS adaptés à la machine

  6. ocvalidate

    Validation de la configuration par l’outil officiel OpenCore avant toute écriture

  7. support

    Image ISO hybride bootable (Linux : clé USB ou VM QEMU) ou écriture directe sur clé USB (Windows)

Une ligne, Linux ou Windows

Sous Windows, ouvre PowerShell en Administrateur pour l’écriture USB. get.ps1 installe Python et Git via winget s’ils manquent ; le partitionnement passe par diskpart, fourni avec Windows.

À savoir avant de lancer

Aucun outil ne garantit un boot du premier coup. Voilà exactement où sont les limites.

  • en ligne
    Installeur « recovery »

    macOS est téléchargé pendant l’installation : connexion requise. Un installeur complet hors-ligne exige createinstallmedia, qui n’existe que sous macOS.

  • automatisé
    ACPI, USB et Wi-Fi

    SSDT universels boot-safe (EC, USBX, AWAC, plugin-type, PNLF), USB via SSDT-RHUB, et le kext Wi-Fi choisi selon la version : Intel AirportItlwm ou Broadcom AirportBrcmFixup.

  • point de départ
    L’EFI reste à affiner

    Mapping USB précis via USBToolBox (Windows) ; Wi-Fi Intel sous Sequoia/Tahoe sans build stable, repli sur le build Sonoma, à vérifier ; ACPI très spécifique : SSDTTime et le guide Dortania.

  • Tahoe (26)
    Dernière version macOS Intel

    Mais seulement 4 modèles réels acceptés (MacPro7,1, MacBookPro16,1/16,2, iMac20,1/20,2) : l’installeur refuse un SMBIOS spoofé qui n’en fait pas partie. macOS 27 sera Apple Silicon uniquement.

  • portables
    Plus délicats

    Batterie, veille, Wi-Fi et USB demandent presque toujours des réglages supplémentaires.

easy-hackintosh repose sur OpenCorePkg, les kexts Acidanthera et le guide Dortania.

Aucun binaire macOS n’est redistribué : la recovery est téléchargée depuis les serveurs Apple. macOS est sous licence Apple pour du matériel Apple : vérifie que ton usage respecte l’EULA. Projet non affilié à Apple Inc.
